欢迎来到我的博客！这是第一篇文章。

## 为什么写博客

写作是对思考的整理。把学过的东西写下来，既能加深理解，也能帮到遇到同样问题的人。

这个博客用 [Hexo](https://hexo.io/) 搭建，托管在 GitHub Pages 上，通过 GitHub Actions 自动部署——每次写完文章 push 一下，网站就自动更新了。

## 博客能做什么

- 记录技术笔记和踩坑经验
- 分享读书、工具和效率心得
- 用 Markdown 专注内容，不用操心排版

## 常用命令

文章写好后，本地预览和发布都很简单：

```bash
hexo new "文章标题"   # 新建文章
hexo server           # 本地预览
hexo generate         # 生成静态文件
```

在这个项目里，你只需要双击 `update.bat`，剩下的交给自动化。
