我裂开了。我真的裂开了。谁懂啊家人们！！！！！！

事情是这样的。我就是想写一个博客。就。写。一。个。博。客。我有什么错？？？？我错在哪了？？？我上辈子是砸了 GitHub 的祖坟吗？？？？

## 第一回合：push 被拒

我信心满满敲下 `git push`，结果——

```
! [rejected] master -> master (fetch first)
```

？？？？？？我刚建的仓库啊！！里面能有啥！！你 fetch 个锤子啊！！！！

打开一看，好家伙，里面躺着两个 README。README.en.md、README.md。我懂了，GitHub 你好事是吧，你初始化是吧，你给我安排得明明白白是吧。我谢谢你啊！！！谢谢！！！

## 第二回合：404

终于 push 上去了，我兴冲冲打开 `https://dlp-sys.github.io/`——

**404。Site not found。**

我人傻了。我盯着屏幕看了整整三十秒。三十秒！！我连呼吸都忘了！！我甚至开始怀疑是不是我自己的名字打错了！！！

后来才知道，Pages 的 Source 还选着"Deploy from a branch"，得手动改成 GitHub Actions。改完还要等几十秒。几十秒啊朋友们！！那几十秒我感觉过了一个世纪！！我连咖啡都喝完了两杯！！！

## 第三回合：src refspec main does not match any

换了个仓库，我又双叒叕 push。这次直接：

```
error: src refspec main does not match any
```

我：？？？？？

main 呢？？我的 main 呢？？？我 `git branch -M main` 了啊！！！它怎么就不 match 了？？？

一个小时后我恍然大悟——我他妈根本没 commit 啊！！！空仓库哪来的分支！！！我对着空气 branch -M 了！！！我跟我自己的影子说了半天话！！！

## 第四回合：网络 502

终于全都配置好了，推送的时候——

```
CONNECT tunnel failed, response 502
```

我笑了。我真的笑了。我坐在电脑前笑出了声。隔壁工位都探头看我，以为我终于疯了。

是的我疯了。我就是被这个 502 逼疯的。我等了十五秒，三十秒，一分钟。我甚至开始跟代理聊天："你行不行啊，你倒是说话啊。"它不理我。它高冷得像我前任。

然后突然——

```
main -> main
```

它！！！通！！！了！！！那一刻我差点从椅子上弹起来！！！我宣布这一刻比我看过的任何一部科幻片都震撼！！！

## 第五回合：博客标题

我寻思都搞定了吧，结果打开博客——

**李明的博客**

我：………………

我叫鹏飞啊！！！鹏！飞！啊！！！我把配置文件翻了个底朝天，改了 author 改 title，改了 title 改 blog_title，改了 blog_title 改 slogan，改到第六遍，它终于变成了"鹏飞的博客"。

那一刻我不是开心，我是麻木。一种历经沧桑之后的、出世的平静。

## 写在最后

现在你看到的这个博客，是用了：

- Hexo 8.1.2
- Fluid 1.9.9
- GitHub Actions
- 我整整两周的头发

换来的。

如果你觉得这个网站还不错，请记得：每一个看似平静的静态页面背后，都有一个曾经在深夜对着 404 疯狂刷新的可怜人。

我没事。我很好。我真的很好。（咬牙切齿）

下次谁再跟我说"搭个博客很简单，几分钟的事"，我直接把这篇文章甩他脸上。微笑。:))
